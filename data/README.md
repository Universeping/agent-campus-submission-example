# 业务资料、规则与测试配置

资料准备基线为 v0.1.0。用户希望参考抖音、快手及剪映、必剪等知名平台和产品的官方资料。[sources.md](sources.md) 已登记首轮来源、核验状态与限制；机器可读的素材和规则数据集尚未生成。

## 分类与来源要求

- 官方平台规范：从抖音、快手官方文档选取与脚本相关的有限条目，记录条款位置、URL、核对日期和适用范围。
- 产品事实：从剪映、必剪官方说明提取可支持的具体能力，记录来源/事实 ID、版本或终端限制；资料未说明的价格、效果、准确率与速度不补写。
- 自定品牌/创作配置：项目自行制定的禁用表达、结构建议、长度或语速参数明确标为自定；不能冒充官方品牌手册或平台标准。
- 合成测试数据：明确生成方式，用于缺资料、错误或冲突测试；不伪装成真实产品事实或真实运行记录。

产品素材需要稳定的来源及事实 ID。规则需区分阻止成功交付的硬条件和仅提示改进的建议。执行器对规则的操作化实现与原文分开描述，不承诺平台实际审核结果。

尚待选择首批产品和平台组合，再确定 JSON 字段。公开仓库仅保存必要的简短转述、链接与自建测试数据，不整页复制官方页面。不依赖 `note/`，不提交真实隐私数据。
