# 三个独立本地工具

实现：[src/tools.py](../src/tools.py)。仅使用标准库，可直接调用函数或通过 `python3 -m src.tools` 执行，不读取 `.env`，不调用模型。先完成工具，再接 Agent 循环；后续离线 Mock 针对模型接口，不替代这三个工具的实际计算。

当前工具函数、CLI 帮助和 Python 类型注解尚未转换为模型可见的 description/参数 JSON Schema。调用适配和模型选择能力仍待实现，见 [方案文档](02-solution.md#面向模型的工具适配待实现)。适配时从可信状态注入资料、品牌规则与时长限制，不将这些核验依据交由模型重写。

## 素材检索

`search_materials(query, material_ids=None, *, materials=None)` 返回 `SearchResult`，非法的空查询返回 `ToolError`。

- `material_ids` 是允许检索的 ID 白名单：`None` 表示全部，空列表表示不允许任何素材；未知 ID 返回错误，不能悄悄放宽范围。
- 默认从 `data/materials.json` 读取资料；调用者可通过仅关键字参数 `materials` 注入已加载的 `Material` 列表。
- 查询按空白分隔为多个关键词，做 OR 子串匹配；对照素材 ID 与事实文本，使用 Unicode NFKC、忽略大小写与空白的比较。
- 返回原始 `Material`，不改写事实。不做中文分词、同义词扩展或向量检索；长查询没有命中时，应由模型观察空结果并调整查询。
- 空结果无错误；文件不可读、资料格式异常或未知 ID 有明确错误，便于与“没有素材”区分。

```bash
python3 -m src.tools search --query 字幕 --material-ids P01
```

## 时长估算

`estimate_duration(script, target_seconds)` 返回 `DurationResult`，非法参数返回 `ToolError`。估时是项目自定假设，不是平台规定或实际配音测量。

| 项目 | timing-v1 计算口径 |
| --- | --- |
| 朗读范围 | 仅旁白；标题和画面描述不朗读。 |
| 语速 | 每个字母或数字（包括汉字）按 4 字符/秒计算；数字与外语也逐字符计数。 |
| 短停顿 | 逗号、顿号、分号、冒号各 0.2 秒。 |
| 长停顿 | 句号、问号、感叹号各 0.4 秒。 |
| 每镜最短 | `max(2 秒, 字符数 / 4 + 停顿)`。 |
| 转场 | 第二镜起每镜另加 0.3 秒。 |
| 精度与总时长 | 按整数百分秒计算每镜，再由报告汇总；通过条件为总时长不超过用户上限。 |

报告携带 `method` 解释假设，并由工具填入实际脚本版本和指纹。该公式不理解英文单词读音、数字展开、情绪语速、实际素材播放长度或并行声音；后续可替换估时策略并重新验证。

```bash
python3 -m src.tools estimate --script examples/tool-validation/input-script.json --target-seconds 30
```

## 事实与品牌规则检查

`check_rules(script, materials, brand_rules)` 返回 `RuleCheckResult`，无法执行的规则或非法上下文返回 `ToolError`。检查标题、每镜画面与旁白，不仅检查旁白。

内置 `FACT-REF` 核对来源 ID 是否存在；`FACT-SUPPORT` 核对表达是否在明确支持的范围内。品牌规则 B01 的“不虚构”通过该事实检查实现。完整报告记录内置规则及提供的品牌规则 ID。

首版受控范围：

1. 产品事实句需逐句匹配所引素材的完整原文，仅规范化 Unicode、空白、大小写和句末标点，不根据关键词相似推断支持。旁白按中文句末标点、问号、感叹号、分号和换行分句。
2. 分镜事实必须由该镜头的引用支持，不能借用另一个分镜的引用；标题可使用脚本汇总引用。
3. “支持字幕”不能自动推出识别、翻译或准确率；百分比也只有对应原文与正确引用同时存在才可通过，不采用“一律禁数字”的替代判断。
4. 非事实的创意表达仅允许下表。超出范围返回 `unsupported_expression` 与“无法核验”，不把它断言为事实错误。模型后续需在提示中获得该列表，并据反馈修改。

| 字段 | 项目自定的允许表达 |
| --- | --- |
| 标题 | 给视频加字幕；视频字幕小课堂；新手字幕入门；字幕功能介绍。 |
| 画面 | 字幕示意画面；展示视频画面；展示字幕示意画面；片尾提示画面；标题卡片。 |
| 旁白衔接 | 今天聊聊视频字幕；先看看示意画面；我们开始吧；你会给视频加字幕吗；给视频加字幕。 |

品牌禁用项用 `BrandRule.forbidden_terms` 显式配置，对标题、画面、旁白做字面匹配；字段默认空，兼容当前最小 JSON。规范化大小写、全角字符和空白，不做同义词识别。`rule` 是说明文本；任意自然语言规则不交给模型或关键词猜测执行。没有禁用词列表时，目前仅支持 B01 的既定事实约束，其他规则返回 `unsupported_rule`，不能当作检查通过。

```json
{"id": "B02", "rule": "禁用词列表", "forbidden_terms": ["全网第一"]}
```

```bash
python3 -m src.tools check --script examples/tool-validation/input-script.json
```

限制：这是原文与封闭表达检查，不是开放域自然语言蕴含、素材真实性鉴定、完整平台审核或品牌政策理解器。可有明显误拒，不接受未覆盖表达并不代表它必然不实。规则、素材和估时配置变化后的历史结果失效仍需后续运行器处理；模型不能自己填写通过报告。

## 独立运行与错误

CLI 输出 JSON。退出码：0 为执行成功（检索可能为空），1 为实际检查不通过，2 为工具或输入错误。文件不可读、非法 JSON、重复 ID、未知规则等不包装为通过结果。命令参数解析错误由 argparse 报告。

`load_materials` / `load_brand_rules` 加载现有数组格式；`load_script` 加载嵌套脚本，并核对可选的派生来源和指纹字段，不信任外部提供的旧指纹。函数接口使用 schemas 对象；CLI 负责文件转换。

测试与实际输出见 [工具验证索引](../examples/tool-validation/README.md)。这些记录仅证明本地工具可运行，不证明模型能选工具、修订脚本或完成 Agent 任务。
