# AI 辅助与个人贡献

## 当前 AI 使用范围

- 使用 Codex 辅助解读考核要求、讨论 CLI / HTTP API、ReAct 循环与工具接入的概念。
- 使用 Codex 检查本机 Git 配置，并生成本起始仓库的目录、忽略规则和文档骨架。
- 用户通过 GitHub 页面创建远程仓库；Codex 配置本地远程地址并准备首次提交。首次提交前检查了目录文件、Markdown 相对链接、行尾空白及忽略规则；这些检查不构成业务测试。
- 尚未生成业务实现，尚未验证真实模型决策效果。
