# 需求与成功标准

业务理解版本：v0.1.0。记录已确认范围及讨论方案，尚未实现。模型已选定；框架最终选择、schemas 和具体检查规则待确认。

## 业务需求

- 选择项目：短视频脚本 Agent；题号待用户补充。
- 目标用户：需要将产品资料转化为短视频脚本的创作者。
- 业务目标：生成有事实依据、满足时长与品牌约束的可编辑脚本，并能够依据检查反馈修改。
- 用户输入：文本形式的主题、受众、平台、目标时长、风格；必填项及默认值待讨论。
- 业务资料：本地文本资料，参考官方平台规则及产品说明，配合明确标记的合成案例、自定品牌与创作规则；不依赖图片、音频或视频，不要求运行时联网抓取平台。
- 预期交付：JSON 与 Markdown，包含标题、分镜、旁白或字幕、分镜及预计总时长、来源引用、风险与任务状态。
- 首版范围：Python CLI、文件/终端 JSON 输入、单 Agent、本地检索/估时/事实与品牌及平台规则检查、DeepSeek V4 Pro 入口、离线 Mock、终端及文件输出、Trace 和可执行测试。
- 缺信息处理：返回具体补充请求并结束本次任务；用户完善 JSON 后重新提交，首版不恢复此前会话。
- 模型：用户指定 DeepSeek V4 Pro；官方标识 `deepseek-v4-pro`。框架建议采用 LangGraph 小型状态图，尚待最终确认与版本锁定。
- 暂不实现：视频生成、配音、会话恢复、网页编辑器、HTTP API、多 Agent 或生产级 Runtime；API 与前端作为后续迭代复用同一业务核心。
- 时长口径建议：目标时长为上限，暂不设置严格下限；估时采用公开说明的项目配置，不冒充平台规定。此口径待最终确认。
- 待明确：输入必填与默认值、schemas、估时公式、事实核验覆盖范围、状态命名、调用预算、平台/产品组合及依赖版本。

## 资料准备与分类

1. 发布平台：抖音、快手的官方规范可作为规则参考。
2. 产品素材：剪映、必剪的官方说明可作为产品事实候选来源；不能把产品说明当作发布平台规则。
3. 项目自定：品牌表达、标题/字幕长度、语速和结构建议明确标为自定配置；无官方依据时不写成官方要求。
4. 合成案例：可构造缺资料、工具失败和冲突场景，注明生成方式；真实输出与 Trace 仍须实际运行得到。

公开来源、核对日期和读取限制见 [来源登记](../data/sources.md)。尚未生成最终数据集，来源登记不等于已经实现相应规则检查。

## 验收映射

以下为实现与验证规划，均未实现、未验证；测试文件和实际证据生成后补充具体路径。

| 验收点 | 计划实现位置 | 计划验证与证据 |
| --- | --- | --- |
| 正常生成完整脚本 | `src/agent.py`、`src/main.py` | 正常案例；核对输出完整、时长与规则检查通过。 |
| 缺关键信息 | `src/main.py`、`src/agent.py` | 缺信息案例；指出缺项并请求补充。 |
| 无素材时动态处理 | `src/tools.py`、`src/agent.py` | 空检索案例；记录模型改写查询或请求补充的行为。 |
| 工具失败时处理 | `src/tools.py`、`src/agent.py` | 工具错误案例；根据观察调整动作或明确未完成。 |
| 超时长后的修正或明确失败 | `src/tools.py`、`src/agent.py` | 超时长案例；记录首稿、修订、重新检查及结果。 |
| 产品事实有依据、来源可追溯 | `src/schemas.py`、`src/tools.py` | 核对产品表达与来源事实；不能只检查来源 ID 存在。 |
| 分镜、版本、时长和检查结果对应 | `src/schemas.py`、`src/agent.py` | 修改脚本后重检，最终结果对应同一版本。 |
| 模型驱动循环与至少两条不同路径 | `src/model.py`、`src/agent.py`、`src/trace.py` | 实际模型运行记录，体现不同工具结果影响后续动作。 |
| 执行上限和明确未完成状态 | `src/agent.py` | 执行上限案例与测试。 |
| 可复现运行、离线入口及证据 | `README.md`、`src/main.py`、`src/model.py` | 补充命令、环境、依赖、三类以上实际案例及测试结果。 |

案例规划见 [examples 索引](../examples/README.md)，实际结果在 [评估文档](03-evaluation.md) 维护。
